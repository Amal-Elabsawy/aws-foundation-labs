# AWS Hands-On Labs

This repo is my practical record of learning AWS by doing. Each lab or activity I complete during my training is documented here, so the work can be reviewed and checked, not just claimed.

## Purpose

- **Practice:** build real AWS resources and troubleshoot them, instead of only reading about them.
- **Evidence:** show what I actually did, with screenshots, commands and verification for each lab.
- **Learning in my own words:** each write-up explains the steps, the problems I hit, and what I would do differently in a real environment.

I'm a System & Support Engineer with an AWS Certified Cloud Practitioner certification, building towards Cloud Support and Junior DevOps roles.

- LinkedIn: https://www.linkedin.com/in/amal-alabsawy/

## What's inside

| Folder | Content |
|---|---|
| `aws-cloud-operations/` | Hands-on activities from the AWS Cloud Operations course |
| `aws-security-foundations/` | Hands-on labs from the AWS Security Foundations course |

Each lab has its own folder with:

| File | Purpose |
|---|---|
| `README.md` | Goal, steps in my own words, verification, troubleshooting, what I learned |
| `commands.sh` | AWS CLI commands I ran, with real output as comments |
| `screenshots/` | Proof of the key steps and the final result |

Some labs are guided, and some are activities where I solved the task myself. The activities and troubleshooting labs show my own approach and the problems I fixed.

## Notes

- Labs were done in training lab environments, not production accounts.
- Account IDs and credentials are removed from screenshots and commands.
- Course instructions are not copied here. Steps are written in my own words.
